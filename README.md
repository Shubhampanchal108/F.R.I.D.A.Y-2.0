# 🤖 FRIDAY 2.0

### Friendly Reliable Intelligent Digital Assistant for Youth

FRIDAY 2.0 is a **Jarvis-like AI agent** built in Python that can **understand natural language, call multiple tools, control the system, help in coding, and act as a personal productivity assistant**.
It is designed as an **API-first, tool-driven, protocol-aware AI agent** with future support for IDE integration and policy-based actions.

---

## 🚀 Key Vision

> “Not just a chatbot, but a real AI agent that can **think → decide → act → verify**.”

FRIDAY 2.0 focuses on:

* Autonomous task execution
* Multi-tool orchestration
* Safe system-level automation
* Developer productivity
