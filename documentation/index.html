F.R.I.D.A.Y 2.0 Documentation

Friendly Reliable Intelligent Digital Assistant for Youth is an enterprise-grade, continuous background desktop AI agent built in Python. Features include Screen Perception, Python Code Execution Sandbox, Proactive Morning Briefings, Deep Research Sub-Agents, ChromaDB Vector Memory RAG, and ADB Mobile Autopilot.

Control Center

Terminal Slash Commands

Control F.R.I.D.A.Y's operational modes, hardware audio, reminders, and system status instantly from the command line.

Command Mode / Function Detailed Description & Practical Use Case How to Trigger
/voice Speech Recognition Mode Switches input mode to continuous microphone voice recognition using PyAudio & SpeechRecognition. Use case: Hands-free coding or listening while working away from keyboard. Type /voice & press Enter
/type Text Typing Mode Switches input mode to silent text typing. Use case: Working in quiet environments, libraries, or noisy rooms. Type /type & press Enter
/audio Speech Voice Drive Toggle Toggles F.R.I.D.A.Y's voice synthesizer ON/OFF (gTTS + pygame). Use case: Mute voice replies during meetings while keeping terminal active. Type /audio
/briefing Morning Briefing Trigger Manually triggers an instant voice briefing containing weather, due reminders, battery status, and news. Use case: Starting your day or resuming work after lunch. Type /briefing
/wakeword Hands-Free Wake Listener Toggles background background wake-word thread. Listens for keyword "Friday" to activate voice input. Use case: Room voice control without clicking anything. Type /wakeword
/status System Health HUD Displays dynamic system status: CPU load %, Battery percentage, active background daemon threads, and ChromaDB vector count. Use case: Checking system resources. Type /status
/reminders Reminders Dashboard Lists all active and due reminders scheduled in local JSON database. Use case: Reviewing daily schedule. Type /reminders
/config Interactive Config Editor Launches terminal wizard to edit API Keys, Provider Base URLs, LLM Model names, and Security Passwords safely. Use case: Changing models or keys. Type /config
/clear Clear HUD Screen Clears terminal console view while preserving session chat history and background daemon threads. Type /clear
/exit Shutdown Agent Safely stops all background threads (Daemon, WakeWord listener), saves persistent memory, and closes CLI cleanly. Type /exit or quit

Brain Loop (Brain.py)

The central cognitive processor. Formats system instructions, loads short-term chat history, injects user profile facts, queries ChromaDB vector memories, parses JSON tool calls, executes functions up to 4 call iterations, and yields final synthesized voice responses.

Background Daemon (daemon.py)

Runs as a non-blocking background thread. Constantly checks local JSON databases for due reminders every 10 seconds. When triggered, it fires native Windows balloon notifications and speaks aloud via voice synthesis.

Access Control ACL (Tool_guard.py)

Enforces origin-based security boundaries. Ensures dangerous system actions (e.g., executing code, deleting files, turning off PC) are restricted to local SERVER origins, while web and mobile clients are granted safe scoped access.

Feature 6

🧠 ChromaDB Vector RAG & Dual Memory

F.R.I.D.A.Y remembers key facts, user preferences, and project context across sessions.

Short-Term Memory

Maintains rolling conversation history in local JSON database for context continuity in current chat session.

Long-Term Vector Memory (ChromaDB)

Automatically extracts user facts (e.g. "My favorite language is Python", "My server IP is 192.168.1.50") and indexes them into ChromaDB vector store for semantic retrieval.

Security Layer

🛡️ Access Control List (ACL Guard)

Granular security matrix preventing unauthorized remote command execution.

Origin Level Allowed Tool Scope Security Restrictions
SERVER (Local PC) Full Access to All 40+ Tools Unrestricted access for local CLI user on primary desktop.
MOBILE (ADB / App) Weather, News, Reminders, WhatsApp, Email, Search Restricted: Cannot run arbitrary Python code or modify local PC system files.
WEB (Remote API) Information Queries, Weather, Reminders, Search Restricted: System automation, screen vision, and file deletion are blocked.

Support & FAQ

Troubleshooting & FAQ

Solutions for common installation and runtime errors.

1. PyAudio Installation Failed on Windows

If pip install PyAudio throws C++ compilation errors, install the wheel directly or run:
pip install pipwin && pipwin install pyaudio

2. ADB Mobile Device Not Detected

Ensure USB Debugging is enabled in Developer Options on your phone. Connect via USB and run adb devices in Command Prompt to verify connection.

3. OpenAI / LLM API Key Error

Launch the interactive config editor by typing /config in HUD terminal and verify your API Key and Provider Base URL.
