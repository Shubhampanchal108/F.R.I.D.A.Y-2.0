Installation & 4 Launch Modes

F.R.I.D.A.Y 2.0 can be launched in four modular operating modes depending on your workflow — from a rich Cyberpunk CLI HUD to a floating holographic screen-corner widget.

MODE 1

Cyberpunk Terminal HUD

Full-featured interactive terminal with Rich cyberpunk styling, live status banners, voice/type toggles, and instant audio interruption. 

python index.py
MODE 2

Holographic Corner Widget

Floating Arc-Reactor glowing neural orb with expandable glass HUD chat panel. Summon or dismiss globally anytime with Ctrl + Space. 

python friday_widget.py
MODE 3

Multimodal Live Vision

Real-time screen or camera streaming via Google Gemini 2.5 Live WebSocket API with native Zephyr audio and 25+ in-stream tool executions. 

python Live_mode.py --mode screen
MODE 4

24/7 Background Autostart

Automated Windows Startup daemon with silent VBS wrappers that trigger desktop toast notifications, reminder alerts, and morning briefings. 

scripts\setup_autostart.bat
DEVELOPER & USER SETUP

Quick Installation Guide (Python 3.10+)

Clone the repository, activate a virtual environment, install requirements, and run! F.R.I.D.A.Y is completely modular and self-configuring.

View on GitHub
Step 1: Clone Repo

git clone https://github.com/Shubhampanchal108/F.R.I.D.A.Y-2.0.git

Step 2: Virtual Environment

python -m venv .venv and activate it via .\.venv\Scripts\activate

Step 3: Install & Run

pip install -r requirements.txt then python index.py

Complete PowerShell / Terminal Command Walkthrough

Run the following sequence in Windows PowerShell, Command Prompt, or Terminal:

POWERSHELL / BASH 
# 1. Clone Repository
git clone https://github.com/Shubhampanchal108/F.R.I.D.A.Y-2.0.git
cd F.R.I.D.A.Y

# 2. Create & Activate Virtual Environment
python -m venv .venv

python friday_widget.py

# Optional: Launch Live Multimodal Screen & Webcam Vision
python Live_mode.py --mode screen

System Requirements

  • Supported OS: Windows 10 / Windows 11 (64-bit recommended for full system controls, widget, and autostart). Linux / macOS supported for core agent & Live vision.
  • Hardware: Minimum 4GB RAM (8GB recommended for ChromaDB vector embeddings), Microphone for voice recognition, Speakers/Headphones for speech output.
  • Python Version: Python 3.10, 3.11, or 3.12 (64-bit).
  • Internet Connection: Required for LLM APIs (Gemini, Groq, OpenAI, OpenRouter) and live web tools. Local models (Ollama) supported offline.
Interactive Setup Wizard: On your first launch, F.R.I.D.A.Y detects missing configurations and automatically starts the First-Time Setup Wizard! You will be guided to enter your preferred LLM Provider URL (OpenAI / Groq / Ollama / Gemini / OpenRouter), API Key, User Name, and Access Password.

Dynamic Config Editor (/config)

You can change your settings at any time without editing source files! Simply type /config in the HUD terminal or widget to view or update keys, model names, voice speed, or passwords with masked key privacy.

Modular Folder Restructuring Breakdown

core/

brain.py (Master-Slave coordination), llm_router.py (25+ model pool failover), tool_guard.py (ACL security matrix), context_builder.py (multi-tier system prompts).

agent/

planner.py (autonomous multi-step goal planner), executor.py (verified execution), sub_agents.py (Deep Research & Code Reviewer), task_queue.py, error_handler.py.

Live/

live_session.py (Gemini 2.5 Live WebSocket), audio_stream.py (PyAudio PCM), vision_stream.py (screen/webcam feed), tools_schema.py (25+ live function schemas).

voice/

speak.py (<30ms interruptible audio playback), instant_filler.py (zero-silence audio fillers), wake_word.py (hands-free listener), voice_input.py.

interface/

cli_interface.py (Rich cyberpunk terminal HUD), friday_widget.py (floating pywebview corner HUD & neural orb), app.js, style.css, orb.js.

services/ & memory/

daemon.py (24/7 proactive watchdog thread, toast notifications), rag.py (ChromaDB vector RAG), memory_manager.py (episodic session persistence).

Agent Brain & Planner (core/brain.py + agent/planner.py)

The cognitive headquarters. The planner analyzes directives into atomic steps with verification contracts (content, file_exists, status_ok). The executor handles dynamic replanning, error recovery, and tool callbacks.

Multi-Model Quota Failover (core/llm_router.py)

100% quota resilience. When primary providers encounter HTTP 429 rate limits, the router seamlessly fails over across a resilient pool of 25+ top free models on OpenRouter with automated cooldown tracking.

Access Control ACL (core/tool_guard.py)

Enforces origin-based security boundaries. System operations, file mutations, and code sandboxes are strictly restricted to local SERVER origins, while web and mobile clients are granted safe scoped access.

Instant cut-off control when you need to redirect the conversation without listening to long responses.

Interruption Architecture
  • Immediate Playback Halt: Pressing Ctrl + D, Esc, or q stops PyGame audio mixer in less than 30 milliseconds.
  • TTS Thread Cancellation: Automatically kills active background audio generation threads and purges audio queues.

100% Resilience

🔀 Multi-Model Quota Failover Router (core/llm_router.py)

Never get stopped by rate limits or HTTP 429 quota exhaustion errors again.

F.R.I.D.A.Y connects to your primary configured model (OpenAI, Groq, Gemini, Ollama). If that provider runs out of credits or encounters an HTTP 429 rate limit, the router immediately cycles through a verified fallback list of 25+ high-tier models on OpenRouter (including Llama 3.3 70B, Qwen 3 Coder, Gemma, DeepSeek R1, Nemotron, Mistral) with automatic cooldown tracking.

🛡️ Access Control List (ACL Guard)

Granular security matrix preventing unauthorized remote command execution.

SERVER (Local PC) Full Access to All 40+ Tools Unrestricted access for local CLI user on primary desktop.
MOBILE (ADB / App) Weather, News, Reminders, WhatsApp, Email, Search Restricted: Cannot run arbitrary Python code or modify local PC system files.

Support & FAQ

Troubleshooting & FAQ

Solutions for common installation and runtime errors.

1. PyAudio Installation Failed on Windows

If pip install PyAudio throws C++ compilation errors, install the wheel directly or run:
pip install pipwin && pipwin install pyaudio

2. ADB Mobile Device Not Detected

Ensure USB Debugging is enabled in Developer Options on your phone. Connect via USB and run adb devices in Command Prompt to verify connection.

3. OpenAI / LLM API Key Error

Launch the interactive config editor by typing /config in HUD terminal and verify your API Key and Provider Base URL.
